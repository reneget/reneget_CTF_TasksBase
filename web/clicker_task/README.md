## Описание

Веб-приложение кликера, которое по сути своей является пустышкой. Для пользователя ставиться задача набрать 1 млрд кликов, что в итоге выведет флаг на приветсвенную таску. Кроме того веб приложение имеет много тупиковых ответвлений, которые не видут к конечному результату (все тупиковые решения перечисленны в [README_impasses.md](README_impasses.md).

## Решение

1. Найти `/flag` и обнаружить там ошибку загрузки флага с ошибкой у которой будет id `LogID405`.
2. В чате разработчиков `/chat` можно найти упоминание логирования и Grafana и путь до конфига  `/app/config/monitoring.env`.
3. Использовать path traversal в `/chat/file?name=../../config/monitoring.env` и прочитать логин/пароль от Grafana `ops_viewer`/`clk_logs_are_not_for_users`.
4. Открыть стандартный порт Grafana `http://<ip>:3000`, и войти под viewer-пользователем креды от которого мы получили на предидущем шаге.
5. В дашборде `clicker` нужно отфильтровать логи по полученному нами логу `LogID405`, получить флаг.
